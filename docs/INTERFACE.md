## 0. 信息架构（三层下钻）

```
顶栏（常驻）：无极 · 本周净额/我的投入/命中率 · [工作台|任务|Agent] · ⌘K 快速发起 · 待处理 N

一级 · 工作台（默认首页）……「现在怎么样、有什么需要我」
    ├─ 待我处理        审批与确认的前 3 条 + 「查看全部」→ 待处理抽屉
    ├─ 进行中的任务    精简列表（状态/执行者/进度/最新动态）→ 点进任务详情
    └─ Agent 概览      一排卡片（状态/在单数/成本）→ 点进 Agent 详情

一级 · 任务 ………………「全部任务怎么管」
    └─ 二级 · 任务详情  整页横向 DAG 工作流：节点（状态/执行者/进度）+ 产物卡
                        + 运行时序面板 + 就地编排（判断选项 / 产出审批 / 用人决定，
                        「等你」的门在节点上直接处理，不再跳第二个页面）

一级 · Agent ………………「编制怎么管」
    └─ 二级 · Agent 详情 抽屉：职责 / 自治级 / 在单任务 / 本周账 / 暂停·停用 / 招募

全局抽屉（不占层级）：
    ├─ 待处理（C）      决策 / 确认 / 知情 三档收件箱
    ├─ 账本（L）        事件 / 引用 / 数字 三镜片
    └─ 快速发起（⌘K）   问答（气泡，不落盘）/ 派任务（排方案 → 用人审批）
```

**主循环**：开机落地工作台 → 清「待我处理」→ 扫「进行中的任务」→ 下钻任务详情操盘（或进 flow 画布）→ 回来。没有需要你的事时，工作台是安静的。

**下钻规则**：一级只做概览与分流，每屏回答一个问题；二级才见全量信息与操作；详情统一用右侧抽屉（任务、Agent），复杂空间操作（flow 画布、领域工作台）才占整屏。

## 1. 术语表（唯一的词，处处相同）

| 词 | 义 | 不用 |
|---|---|---|
| **任务** | 一件委派出去、有步骤有产物的工作 | 业务/产线/车道/线 |
| **Agent** | 系统里的自动化执行者，按职能命名 | 匠人/匠籍/员工 |
| **待我处理** | 需要人决策或确认的事项队列 | 工单桌/呼叫/请示 |
| **用人审批** | 系统派任务后排的执行方案，等批准 | 召唤审批/召唤卡 |
| **收件箱三档** | 决策（只有你能定）/ 确认（过目即可）/ 知情（看一眼） | 安灯/黄灯呼叫 |
| **账本** | 全系统可审计记录：事件/引用/数字 | 总账/谱 |
| **快速发起** | 底部常驻输入：问答 / 派任务 | 召唤栏/问书/书态 |
| **状态** | 进行中 · 等待你 · 阻塞 · 等待外部 · 已完成 · 派单中 · 已暂停 | 在跑/等我/停线/灯语 |

状态色五色保留为视觉词汇（绿=进行中，黄=等待你，红=阻塞，蓝=等待外部，灰=完成），但永远配文字标签，颜色不是唯一通道。

## 2. 各页信息结构

### 2.1 顶栏（常驻）

- 左：品牌（无极）；
- 中：三个关键指标——本周净额、我的投入（分钟）、判断命中；
- 右：视图导航（工作台 / 任务 / Agent）· ⌘K · 待处理按钮（计数 + 脉冲，清空转绿）。

### 2.2 工作台（首页，一级）

一屏三段，自上而下按注意力优先级排列：

1. **待我处理**：决策与确认的前 3 条（谁提交、哪条任务、要做什么、预计几分钟、首选动作按钮），尾部「查看全部 N 条」开抽屉。审批（用人方案）混排在此，按决策优先。
2. **进行中的任务**：全部非完成任务的一行式列表——编号、名称、状态、执行者、进度（n/m 步）、最新动态一句话；点行开任务详情抽屉。
3. **Agent 概览**：一排紧凑卡片（名字、职责、状态、在单数、本周成本），点卡开 Agent 详情；尾部「管理全部」进 Agent 页。

空态：「没有需要你处理的事」是明确信号，不是空白。

### 2.3 任务（一级）→ 任务详情（二级）

- 列表：全部任务 + 状态筛选（全部 / 进行中 / 等待你 / 阻塞 / 已完成），行结构同工作台但信息更全（含产物）。
- **任务详情抽屉**：任务信息（状态/执行者/创建时间/预算）· 步骤列表（纵向，每步：状态 + 名称 + 执行者 + 进度）· 运行日志（时间轴）· 产物（按形态开编辑器/展示器）· 操作（暂停 / 从某步重跑 / 打开 flow 画布）。

### 2.4 Agent（一级）→ Agent 详情（二级）

- 列表：卡片网格——名字、职责、自治级、在单任务数、通过率、本周成本、状态；「招募 Agent」空位卡。
- **Agent 详情抽屉**：职责 · 自治级（L1 产出必审 / L2 抽检可重试 / L3 全自主，可调）· 在单任务 · 本周账（运行/通过/返工/成本/找我次数）· 暂停 / 恢复 / 停用。

### 2.5 待处理（全局抽屉，C）

三档分组：决策（只有你能定）/ 确认（过目即可，可批量）/ 知情（看一眼，可全部已读）。票面：谁提交、哪条任务、预计耗时、动作按钮组；动作真实驱动任务状态。

### 2.6 账本（全局抽屉，L）

三镜片：**事件**（全系统时间线，按类型筛选）· **引用**（产物与任务的 derived/binds/supports 关系表）· **数字**（净额、我的分钟去向、Agent 成本）。

### 2.7 快速发起（⌘K，底部常驻）

- **问答**（默认）：气泡应答，不落盘；
- **派任务**：写清要什么结果 → 系统排执行方案（谁执行、几步、成本）→ 用人审批 → 批准后入列开工。

## 3. 领域工作台（OPC / coding / 资产）

领域工作台从顶栏进入（二期），各自带详情页与领域视图（OPC 的产线视图、coding 的评审视图）。壳对台的约束不变：一台一体相用、不设私有收件箱、深度三层、共用原子件。

## 4. 注意力契约

只有三档打扰：**决策**（顶栏脉冲 + 计数，不可忽略）/ **确认**（仅计数，可批量）/ **知情**（不亮灯，进抽屉才见）。Agent 永不直接打断人——一切经审批门进待处理。人写直通，Agent 写必经门。

## 5. 键盘

| 键 | 动作 |
|---|---|
| ⌘K | 快速发起 |
| 1 / 2 / 3 | 工作台 / 任务 / Agent |
| C | 待处理抽屉 |
| L | 账本抽屉 |
| F | 聚焦链（详情内） |
| ⏎ / Esc | 进入 / 逐层退回（详情 → 列表 → 工作台） |
| ⌘Z / ⇧⌘Z | 撤销 / 重做 |

## 6. 视觉

钢灰工坊皮保留为**纯视觉**（四层钢灰、状态五色、七段计数、DSEG7、Barlow Condensed + PingFang、方角铁则），见 `demo/shell/DESIGN.md`。术语与信息架构以本文件为准。签名动效收敛为两条：新内容「渐显入场」，等待你的事项「缓慢脉冲」；其余动效仅状态反馈，全部尊重 `prefers-reduced-motion`。
